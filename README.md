# Chainsaw Audio Classifier

A Python-based machine learning application designed to detect and classify chainsaw sounds within audio datasets. This tool processes batches of audio files from a designated directory to identify acoustic signatures associated with illegal logging or forest activity monitoring.

## Features

* **Batch Processing:** Scans an entire folder of audio recordings automatically.
* **Temporal Localization:** Detects and flags the specific **start and end times** of detected chainsaw events within each audio file.
* **Confidence Scoring:** Outputs probability percentages indicating the model's confidence level for each detection.
* **CSV Export:** Generates a structured CSV report summarizing the findings (file name, confidence score, start time, and end time).

## Repository Structure

* `ML_app.py`: Main application script for batch inference and evaluation.
* `ML_model/`: Directory containing the trained machine learning model files.
* `How to run the program.pdf`: Detailed documentation and setup guide.
* `Dockerfile`: Configuration for containerized deployment.
* `requirements.txt`: Python package dependencies.
